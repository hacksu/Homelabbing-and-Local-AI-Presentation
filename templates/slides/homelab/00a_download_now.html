BEFORE WE START

START YOUR DOWNLOAD NOW

To run AI locally you need two things: a harness (the app that runs the model) and the model itself (~1 GB). Start both now so they're ready for the second half. Pick one harness.

Ollama - terminal, Mac or Windows

1. Install the harness from ollama.com/download
2. Open Ollama and leave it running
3. Get the model: in Terminal (Mac) or PowerShell (Windows), run
ollama pull qwen2.5:1.5b

Needs macOS 14+ or Windows 10 22H2+

LM Studio - chat window

1. Install the harness from lmstudio.ai/download
2. Open LM Studio and go to Discover
3. Get the model: search Qwen2.5-1.5B-Instruct, download the GGUF Q4_K_M variant

Needs an Apple Silicon Mac (macOS 14+) or an x64 PC with AVX2. Intel Mac? Use Ollama.
