WHAT CAN YOUR HARDWARE HANDLE?

Model size — Smaller models usually need less memory. Check whether their answers are good enough for your task.
Quantization — Storing the weights with less precision saves memory and can affect answer quality.
Context — Longer prompts and conversations use more working memory.
Speed — A model can fit in memory and still feel slow, especially when it runs on the CPU.
Start with a small model and test it on a task you care about.
